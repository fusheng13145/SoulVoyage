# 11.8 中优项（M-01–M-07）评估与排期建议

> 依据：基线 spec §4.3、tasks.md 11.8。
> 性质：**只做评估，不实施**。结论用于逐项审批与 Batch 7 排期。
> 原则：优先选技术上更合理、可维护、可回滚的方案，不以“改动小”作为排序依据。

## 0. 结论摘要

| 优先级 | 项 | 建议首期范围 | 成本 | 风险/审批 |
|---|---|---|---|---|
| P1 | M-07 推荐解释性 | 计划项/练习推荐附确定性理由（压力源/误区/情绪来源） | S–M | A（只读派生）；若加 `reason` 列则属 A+迁移 |
| P1 | M-03 报告导出 2.0 | 单报告打印页 + 档案目录/分页；继续用浏览器打印，不引入 PDF 库 | S–M | A（只读/前端） |
| P2 | M-02 KG 可视化 | 只读 `/kg/graph` + ECharts 关系图，先做确定性关系投影 | M | A（只读）；需先定义“相关”关系语义 |
| P2 | M-06 审计检索/导出 | 日期/target 过滤 + CSV 导出 + 导出审计；批量冻结另议 | S–M | A（只读）；批量冻结属 B |
| P3 | M-01 语音日记 2.0 | 首期只做波形/录音态/转写校对；离线队列与分段后置 | S（首期） | A；离线音频留存属 B |
| P3 | M-05 多端一致性 | 草稿 `updatedAt` 冲突提示 + 任务/偏好刷新；不做自动合并 | M | B-?（草稿语义变更，需审批） |
| P4 | M-04 会话与设备管理 | 设备会话表/Redis 注册、单设备下线、异常登录提示 | M | **B-07 必须逐项审批** |

**推荐顺序：M-07 → M-03 → M-02 → M-06（只读部分）→ M-01 首期 → M-05 → M-04。**
理由：先把“可解释、可带走、可看见”的只读价值交付；把涉及音频留存、草稿冲突、认证会话的改动放到后面，逐项审批。

## 1. 逐项评估

### M-07 推荐解释性（P1，S–M，A）

**现状**
- `SupportAgent` 已产出 `matchedExercises`、`planItems`、`trace.stressors`、`kgSource`；`PlanService` 物化为 `plan_item`。
- 用户端只看到 `guidance`，没有“为什么推荐这个练习/场景”的确定性说明。

**建议首期**
- 不依赖 LLM 二次生成：在物化/读取时按规则生成 `reason`：
  - 练习：命中 `applyEmotions` 的主导情绪 + 当前压力源；
  - 场景：`recommendedFor` 命中压力源 + `goalDimensions`；
  - 科普：`aboutTags` 命中压力源/情绪。
- 输出新增 `reasons: string[]`（1–2 条，短句），措辞只描述“匹配依据”，不做诊断、不承诺疗效。
- 方案取舍：优先在 `active()` 读取时由 `plan_item` + `sourceReport` 派生，避免新增列；若后续要做历史解释留痕，再加 `plan_item.reason`（V4 迁移）。

**依赖/风险**
- 只读派生，不改计划编排/风险判定；不触碰 C 类。
- 需确认报告 `trace` 解密读取的频次与缓存；建议一次计划视图只读一次。

**验收**
- 每个计划项/推荐在无 LLM 时也有稳定理由；同一输入理由一致；文案无诊断词。

### M-03 报告导出 2.0（P1，S–M，A）

**现状**
- `ArchiveController` 导出完整档案快照 JSON，前端 `ArchiveView` 已有打印页/标题页，`window.print()` 存 PDF。
- 无单报告导出入口；打印页缺少目录/分页控制。

**建议首期**
- 在 `ReportDetailView` 增加“打印/存为 PDF”，复用报告详情数据，不新增后端 PDF 依赖。
- 档案打印页补目录、章节锚点、`break-before: page`；页眉页脚仅放报告类型/日期，不放敏感正文。
- 不引入 iText/PDFBox 等重依赖；继续遵守“PDF 渲染降级为打印样式页”的既有风险预案。

**验收**
- 单报告可打印；档案目录可跳转；打印预览无截断；导出仍走现有一次性快照/审计。

### M-02 知识图谱可视化（P2，M，A）

**现状**
- `ContentStore` 已暴露 distortions/psyTopics/commCases/scenes/exercises；`KgSearchService` 只提供闭集候选卡片。
- 管理端有 `kg/graph` 审计计数；用户端无图谱浏览。
- 数据关系目前以 `distortionRefs`/`techniqueRefs`/`recommendedFor`/`aboutTags` 为主，并非完整因果图。

**建议首期**
- 新增只读 `GET /kg/graph?focus=...&depth=...`，节点来自 ContentStore，边只使用**已存在、可解释**的引用：
  - COMM_CASE → DISTORTION / STRENGTH_TECH；
  - SCENE → STRESSOR（recommendedFor）；
  - PSY_TOPIC → STRESSOR（aboutTags）；
  - EXERCISE → EMOTION（applyEmotions）。
- 前端 ECharts graph，限制节点数（如 ≤80），默认聚焦“我的压力源/误区”；边文案用“相关/适用于”，禁止“导致/治疗”。
- Neo4j 不是前置条件：DB 真源即可；Neo4j 就绪后只换数据源，接口不变。

**风险**
- 关系语义容易被误读为诊断/因果；需文案与图例约束。
- 需要先补一条“关系投影”规则，避免前端各自拼关系。

**验收**
- 同一内容版本图稳定；未知引用不渲染或标灰；图谱无诊断结论。

### M-06 管理端批量操作与审计检索（P2，S–M，A + B）

**现状**
- `AdminOpsController` 审计已支持 `userId/action` 过滤与分页；无日期/target 过滤、无 CSV、无批量冻结。
- 批量冻结会一次性吊销多用户令牌，属安全敏感写操作。

**建议首期（只读）**
- 审计增加 `from/to/target` 过滤；新增 CSV 导出（流式、列白名单、脱敏 IP 可选），导出动作本身写审计。
- 不做批量冻结；如确需，另立 B 项：逐用户确认、幂等、失败清单、二次审计。

**验收**
- 过滤组合正确；CSV 不含手机号/正文；导出动作可在审计中追溯。

### M-01 语音日记 2.0（P3，首期 S，A；离线 B）

**现状**
- `useVoiceNote` 已有 0.7–90s 录音、ASR、追加转写；后端有 5MB/格式魔数/限流。
- 无波形、无暂停/续录、无分段/时间戳、无离线草稿队列。

**建议首期**
- 波形：Web Audio `AnalyserNode` 实时画幅度，不存音频；录音结束即释放麦克风。
- 转录校对：保留现有“追加不覆盖”策略，增加“替换本段/撤销”轻量操作。
- 分段/时间戳依赖 ASR 返回 segments；当前 `AsrClient` 无该字段，先不承诺。
- 离线队列需要本地保存音频，涉及隐私与存储配额，列为后续 B 项（需明确留存时长/清除策略）。

**验收**
- 波形不增加上传体积；权限拒绝/超时/过短路径话术不变；无音频落盘。

### M-05 多端一致性（P3，M，B-?）

**现状**
- Web/小程序共用 `/diaries/draft`（加密单行）与 `/preferences`；小程序已能调 `/tasks`。
- 草稿响应只有 `content`，无版本/更新时间；两端同时编辑会静默覆盖。

**建议**
- 草稿响应增加 `updatedAt`；保存时带 `expectedUpdatedAt`，冲突返回 409 + 服务端最新摘要，由用户选择保留哪端。
- 偏好冲突用字段级 last-write-wins，不做自动合并。
- 任务状态在页面 `focus`/`visibilitychange` 时刷新，SSE 仍为事实源。
- 不引入 CRDT/复杂协同；当前场景不需要。

**风险**
- 草稿是加密内容，冲突摘要不能回传正文；只回时间与长度。
- 属 B 类草稿语义变更，需单独审批。

### M-04 会话与设备管理（P4，M，B-07）

**现状**
- JWT access/refresh + refresh 轮换、jti 黑名单、epoch 全量吊销；无设备列表/单设备下线。
- 无异常登录提示。

**建议**
- 先做“会话注册表”（Redis hash：jti、UA、IP 哈希、lastSeen、createdAt），登录/刷新时更新；
- 设备列表只回 UA 摘要/IP 归属地，不回完整 IP；单设备下线=拉黑该 refresh jti；
- 异常登录提示需要通知渠道与阈值，后置。
- 必须走 B-07 审批；不得改变现有 refresh 重用检测与 epoch 语义。

**验收**
- 单设备下线不影响其他设备；全量登出语义不变；Redis 故障按现有降级/503 边界处理。

```text
  M-07 推荐理由（派生）

Batch 7B（只读可视化/运营）
  M-02 /kg/graph + 前端关系图
  M-06 审计过滤 + CSV（只读）

Batch 7C（体验/一致性）
  M-01 波形 + 转写校对
  M-05 草稿冲突提示（需 B 审批）

Batch 7D（安全，单独立项）
  M-04 设备会话（B-07）
  批量冻结（B）
  离线音频队列（B）
```
